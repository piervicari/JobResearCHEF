## Taxonomy benchmark

The versioned dataset is `data/benchmarks/taxonomy_v1.csv`. Final decision accuracy, INCLUDE
precision and INCLUDE recall are 100% on 46 cases at this baseline. Component accuracy is 100% cyber,
97.8% seniority and 100% geography. The single component mismatch is a product-policy ambiguity for
`Product Manager Internship`: the current seniority gate treats `manager` as an exclusion, while the
benchmark treats `internship` as early-career. The final decision remains the expected `EXCLUDE`
because the role is non-cyber.

This curated benchmark is a regression baseline, not a statistical claim about all live vacancies.
